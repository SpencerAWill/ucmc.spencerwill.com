# Public legal/disclosure pages, the homepage, sign-in, and the
# colophon are crawlable. Member-data surfaces (auth-gated by
# `requireApproved` / `requirePermission`) are disallowed so a

# accidentally cache any session-conditional response. The
# sitemap below enumerates the public set explicitly so search
# engines don't have to discover it.
